# Security policy

## Supported versions

| Component                                        | Supported          |
| ------------------------------------------------ | ------------------ |
| GitHub App hosted at https://beepboop.kjanat.dev | Current deployment |
| Actions in `actions/`                            | Latest `v1` tag    |
| CLI `@kjanat/beepboop` on npm and JSR            | Latest release     |

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:
https://github.com/kjanat/beepboop/security/advisories/new

Include the affected component, its version or commit, steps to reproduce, and the impact.

Keep the report private until a fix is released.
